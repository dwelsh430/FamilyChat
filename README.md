# FamilyChat
A simple family chat board for home use.

**Open the chat:** https://dwelsh430.github.io/FamilyChat/chat/

It's a single web page that works on phones and computers. Family members' browsers connect directly to each other, and every device keeps its own copy of the chat. There is no central server. See [HOW-IT-WORKS.md](HOW-IT-WORKS.md) for a plain-language explanation and how to invite family.

- `chat/index.html`: the chat page (built file, self-contained)
- `src/`: the source code and build/test scripts
